עמית אוזן · הסטודיו — גרסה עצמאית
=====================================

התיקייה הזו היא האתר המלא: index.html, כל התמונות והסרטונים (img), ספריית התלת־ממד three.js והגופנים (vendor).
הוא לא צריך את Claude ולא צריך חיבור לאינטרנט. האינטרנט נדרש רק לקישורים החיצוניים (אינסטגרם, האתר ב־Wix).

איך פותחים במחשב
-----------------
Windows: לחיצה כפולה על Open-Site-Windows.bat
  נפתח חלון שחור והאתר נפתח בדפדפן. משאירים את החלון פתוח בזמן הגלישה וסוגרים אותו בסוף.
  אם Windows מציג אזהרה ("Windows protected your PC"): More info ← Run anyway.

Mac: לחיצה כפולה על Open-Site-Mac.command
  בפעם הראשונה: קליק ימני ← Open (כי הקובץ לא חתום).

למה לא פשוט לחיצה כפולה על index.html?
  דפדפנים חוסמים אתרים תלת־ממדיים שנפתחים ישירות מקובץ (file://): התמונות על הקירות והסצנה לא נטענות.
  אם בכל זאת פותחים כך, האתר עובר אוטומטית לגרסה רגילה בלי תלת־ממד.

איך מעלים לאינטרנט
------------------
מעלים את כל התיקייה כמו שהיא, עם index.html בשורש, לכל אחסון סטטי:
  · Netlify Drop (app.netlify.com/drop): גוררים את התיקייה לדף ומקבלים כתובת.
  · GitHub Pages, Vercel, Cloudflare Pages, או אחסון רגיל דרך FTP.
אין צורך בשום התקנה או בנייה.

איך עורכים תוכן
---------------
פותחים את index.html בעורך טקסט (למשל VS Code או Notepad++) ומחפשים:
  · const CONTACT  — אימייל, טלפון, אתר, אינסטגרם.
  · const WORKS    — הפרויקטים, הטקסטים והתמונות (נתיבי img/...).
  · const GALLERY / BRANDS — סדר הפרויקטים בקירות ובחלל המותגים.
תמונה חדשה: שמים אותה בתיקיית img ומוסיפים את הנתיב שלה ל־WORKS.
